# Checklist de validação

## Fluxo principal
- [ ] A home mostra apenas hero, dois portais, manifesto curto e rodapé.
- [ ] Educação aparece somente após clicar em Educação.
- [ ] Consultoria aparece somente após clicar em Consultoria.
- [ ] O botão voltar do navegador retorna ao estado anterior.
- [ ] A URL preserva o caminho do GitHub Pages.
- [ ] Links diretos com `?area=educacao` e `?area=consultoria` abrem a jornada correta.

## Visual
- [ ] Não há sequência repetitiva de cards.
- [ ] A fotografia está integrada ao hero.
- [ ] Educação é clara e humana.
- [ ] Consultoria é sóbria e reservada.
- [ ] O azul luminoso é usado apenas como detalhe.

## Responsividade
- [ ] 360 px
- [ ] 390 px
- [ ] 430 px
- [ ] 768 px
- [ ] 1024 px
- [ ] 1366 px
- [ ] 1440 px
- [ ] 1920 px

## Acessibilidade
- [ ] Navegação completa por teclado.
- [ ] Foco visível.
- [ ] Contraste WCAG AA.
- [ ] Diálogos fecham com Escape.
- [ ] Animações reduzidas quando solicitado pelo sistema.

## Publicação
- [ ] Configurar `js/config.js`.
- [ ] Confirmar dados regulatórios.
- [ ] Inserir política de privacidade definitiva.
- [ ] Configurar domínio e canonical.
- [ ] Inserir analytics com consentimento.
